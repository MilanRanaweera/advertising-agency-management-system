## Integration coverage

2. Customer cannot approve their own quotation; originals remain forbidden both before payment and after approval but before invoice delivery. Director's internal feedback is absent from customer results.
3. Public registration cannot assign ADMIN and does not expose password hashes; customer access to user administration is forbidden.
4. Catalogue draft creation/update/publication/removal with a marketing-only publication gate.
5. Consultation creation/editing, CUSTOMER_RELATIONS_OFFICER-only confirmation, staff reply and open-message deletion.

6. Username `admin` authenticates with `admin@2026`, can access user administration, and rejects a wrong password.

7. Admin deletion removes the account from listings, blocks subsequent login, and prevents self-deletion.
8. Project creation is blocked before acceptance.
